# Tasks

## 0. Measured first, 2026-08-30

- Скриншот оператора: пять SHORT-плашек лесенкой, каждая ниже своей линии,
  смещение растёт вниз по стопке. «Если я начинаю их двигать по плашкам —
  линии начинают смещаться и ордер вылетает со своей обычной цены».
- Причина 1 — `layoutOrderCoordinates`: вертикальный анти-оверлап
  (`ORDER_HANDLE_GAP = 24`) цепочкой сдвигал плашки с якоря; `is-displaced`
  вешался, но не имел ни одного CSS-правила — смещение никак не показывалось.
- Причина 2 — `moveOrderDrag` читал абсолютную позицию указателя
  (`coordinateToPrice(clientY - rect.top)`): захват смещённой плашки прыгал
  ценой на величину смещения; захват несмещённой — на пол-плашки от места
  посадки пальца.
- GitNexus: `impact` падает («Database file version: 42, build storage
  version: 40», risk UNKNOWN) — радиус померен grep'ом: `layoutOrderCoordinates`,
  `moveOrderDrag`, `beginOrderDrag`, `ORDER_HANDLE_GAP`, `data-anchor-y`
  приватны для `FuturesWorkstationChart.jsx`; наружу торчит только CSS-правило,
  закреплённое viewport-сьютом.
